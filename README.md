## The renewal question, with numbers

AVABOO is explicitly marked "No recurring", and the second source that lists it says the same thing in different words: the discount applies to the purchase, and renewal is at the normal price.

What that means in cash, on real plans:

- **VPS One** at €5/month: first invoice €4.25, then €5.00. Over twelve months you pay €59.25 instead of €60. The code saves you 75 cents.
- **VPS Ultra** at €40/month: first invoice €34, then €40. Saves €6 once.
- **Cloud Apps** at €12/year with AVAAPPS: first year €10.20, then €12.

Run the numbers before you get excited about a percentage. A 15% one-time code is a rounding error on a monthly plan, and it's worth exactly nothing on invoice two. The coupon sites' claim of 5%/10%/15% off for 3, 6 and 12-month terms would matter far more, because it would compound across a prepaid year, but no code is attached to that claim and AvaHost doesn't list it in the promotions archive. Until a code exists, it isn't a discount.

Two other things affect the real cost. First, a review published in October 2026, citing AvaHost's refund policy, reports a 30-day full refund for first-time hosting accounts with **discounted orders excluded**. If that's accurate, using a coupon could cost you the refund window, which is a bad trade for 75 cents. Confirm with support before you pay, especially on a yearly Cloud Apps order. Second, the same review describes identity checks at the payment stage, so don't assume an anonymous checkout.
